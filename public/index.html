Backup de mis datos

Tu álbum vive solo en este navegador. Si cambiás de celular, actualizás la app, o borrás datos del navegador por error, lo perdés. Descargá un backup de tanto en tanto para no perder tus figuritas, precios y repetidas cargadas.

Sincronizar entre dispositivos

Todavía no conectaste esta app a un proyecto de Firebase, así que la sincronización automática está apagada. Mientras tanto, podés usar el Backup para pasar tus datos a mano entre dispositivos. Mirá el README ("Sincronizar entre dispositivos") para el paso a paso de cómo activarla — son 2 minutos y es gratis.

Elegí un código de álbum (una palabra o frase que solo vos conozcas, ej. familia-gomez-mundial26) y cargalo igual en el celular y en la compu. Cualquiera que sepa ese código puede ver y editar este álbum, así que no lo compartas públicamente.
